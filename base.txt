# API Reference

**Base URL:** `https://maslow-progress-70d3dad7.base44.app/api`

## Setup

```bash
npm install @base44/sdk
```

```javascript
import { createClient } from '@base44/sdk';

const base44 = createClient({
  appId: "68a771320ec4ba9670d3dad7",
  headers: {
    "api_key": "813c92bd6bac4b0db5cd42fdf17dee33"
  }
});
```

## Habit

### Schema

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | Yes | Nome do hábito |
| `description` | string |  | Descrição detalhada do hábito |
| `maslow_level` | `1`, `2`, `3`, `4`, `5` | Yes | Nível da pirâmide de Maslow (1-5) |
| `habit_type` | `quantitative`, `qualitative` | Yes | Tipo: quantitativo (com meta numérica) ou qualitativo (feito/não feito) |
| `frequency` | `daily`, `weekly`, `monthly` |  | Frequência do hábito |
| `target_value` | number |  | Meta numérica para hábitos quantitativos |
| `unit` | string |  | Unidade de medida (litros, horas, etc.) |
| `weight` | integer |  | Peso do hábito para cálculo do progresso (1-5) |
| `icon` | string |  | Nome do ícone Lucide |
| `color` | string |  | Cor personalizada do hábito |
| `is_active` | boolean |  | Se o hábito está ativo |
| `streak_current` | integer |  | Streak atual em dias |
| `streak_best` | integer |  | Melhor streak já alcançada |
| `id` | string |  | Unique record identifier |
| `created_date` | string |  | Record creation timestamp |
| `updated_date` | string |  | Record last update timestamp |
| `created_by` | string |  | Email of the user who created the record |

### Endpoints

### `GET /entities/Habit`
List Habit records

**Parameters:**
- `q` (query): JSON query filter, e.g. {"status":"active"}
- `limit` (query): Maximum number of records to return
- `skip` (query): Number of records to skip (pagination)
- `sort_by` (query): Field name to sort by. Prefix with '-' for descending order, e.g. -created_date

```javascript
const records = await base44.entities.Habit.list();
```

### `POST /entities/Habit`
Create a Habit record

```javascript
const record = await base44.entities.Habit.create({
  // your data
});
```

### `DELETE /entities/Habit`
Delete multiple Habit records

```javascript
await base44.entities.Habit.deleteMany({
  // query filter — WARNING: empty {} deletes ALL records
  name: "Example name"
});
```
